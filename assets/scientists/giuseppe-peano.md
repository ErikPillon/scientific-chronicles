Giuseppe Peano wanted to know exactly what arithmetic actually rested on, so in 1889 he wrote down a set of axioms, now called the Peano axioms, that could generate the entire system of natural numbers from a handful of basic logical statements. It was a foundational moment for modern mathematical logic, an attempt to make sure math wasn't just built on convenient assumptions but on airtight logical footing. He also developed much of the symbolic notation mathematicians still use today for set theory (the symbols for 'belongs to' and 'there exists' are largely his). Later in life he got obsessed with creating a universal simplified language called Latino sine flexione, which never caught on, proving that even brilliant logicians can have a wildly ambitious side project that goes nowhere. ➕🔢
